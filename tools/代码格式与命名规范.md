- 函数参数(parameter)、局部变量(var)、私有字段(field)/私有属性(private property)：**小驼峰**

### 词性

- 类：**名词**

  public class **UIManager**{}

  public class **CardEffect**{}

  public class **MFLauncher**{}  

- 字段、属性、枚举类、枚举值：**名词**。对于UI，常使用btnXXX、txtXXX、pnlXXX的写法

- 函数：**动词**。**对于虚函数、事件触发的回调函数，建议加上On前缀**

- 接口：**以I作为前缀**，所有接口建议统一为以下几种形式

  **ICan**DoXXX：ICanFly、ICanPay

  **IHas**XXX：IHasName、IHasCard

  **I**XXX**able**：IEnumerable、IEquatable

  **IGet**XXX：IGetID

  **ISet**XXX：ISetItem

- 抽象类：**以Base作为后缀**

public abstract class Card**Base** {}

- 泛型：**以T作为前缀**

public Singleton<T>{}

public List<T2> Map<T1, T2>(List<T1> l, Func<T1, T2> f){}

- 枚举类：**以E作为前缀**

public enum **E**Color

{

 Red,

 Violet,

### 布局

- 注释不应写在代码右侧，而是在上面另起一行
- 每行只写一条语句，即使是if(xxx) return的形式，也建议把return写在第二行
- 每行只写一个声明，避免int a,b,c；
- **大括号{}记得换行**，除非{}内没有内容
- **逗号前不空格，逗号后空一格，运算符前后各空一格**

  public List<T2> Map<T1, T2>(List<T1> l, Func<T1, T2> f){}

  a = c + b;

  a=c+b;

- **一行代码过长，将点运算分割到第二行及更多行并缩进一级**

```javascript
Flow.Create()
    .Then(() => GetComponent<SpriteRenderer>().ToCol(Color.black).Easing(Transition.InOutElastic).During(5).Play())
    .Then(() => transform.FromPos(Vector3.left * 5 + Vector3.up * 2).ToPos(Vector3.right * 5 + Vector3.up * 2)
        .ToRot(Vector3.forward * -360)
        .During(2).Play())
    .Delay(() => transform.AddPos(Vector3.down * 4).During(10).Easing(Transition.OutBounce))
    .Then(() => transform.AddRot(Vector3.forward * 1440).During(3).Easing(Transition.InQuad).Play())
    .Then(() => transform.AddScale(Vector3.one * 2).During(3).Play())
    .Run();
```
